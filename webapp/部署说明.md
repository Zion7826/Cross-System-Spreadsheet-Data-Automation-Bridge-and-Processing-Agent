# 跨系统表格桥接智能体 · Web 版部署说明

## 一、组件清单

| 组件 | 位置 | 端口 | 状态 |
|---|---|---|---|
| Web 系统（FastAPI + 前端单页） | `agent_app/webapp/server.py` | 127.0.0.1:8620 | 运行中 |
| 大模型网关（workbuddy2api-hub） | `workbuddy2api-hub/wb_proxy.py` | 127.0.0.1:8788 | 运行中，待绑定账号 |

## 二、启动命令

```bash
# 1) Web 系统
cd agent_app/webapp
python -m uvicorn server:app --host 127.0.0.1 --port 8620

# 2) 大模型网关（OpenAI 兼容）
cd workbuddy2api-hub
python wb_proxy.py --port 8788
```

浏览器访问：`http://127.0.0.1:8620`（智能体），`http://127.0.0.1:8788/`（网关看板）。

## 三、大模型链路

- Web 系统「大模型设置」页已配置：Base URL = `http://127.0.0.1:8788/v1`，模型 = `glm-5.3-flash`（配置落盘 `webapp/llm_config.json`，Key 不回显）。
- 网关本机模式无需密钥；`/v1/chat/completions`、`/v1/models` 均为标准 OpenAI 格式。
- 模型目录含：glm-5.3-flash、glm-5.3、deepseek-v4.1-flash、gpt-6-astra、kimi-k3 等，可随时在设置页切换。

## 四、账号绑定（唯一需要人工的一步）

1. 打开网关看板 `http://127.0.0.1:8788/`；
2. 点页面上的授权链接，用你的 WorkBuddy / CodeBuddy 账号完成 OAuth 登录；
3. 看板显示账号 ready 后，回到智能体「大模型设置」页点「测试连接」，出现「连接成功，模型回复：正常」即链路打通。

## 五、验收自检（Web 端）

「验收自检」页一键运行三条验收：逻辑计算精度 / 格式兼容度 / 抗错鲁棒性，当前 3/3 PASS。
