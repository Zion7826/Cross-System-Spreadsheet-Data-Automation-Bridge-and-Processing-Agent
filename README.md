# 跨系统表格数据自动化桥接与处理智能体

面向企业 ERP / OA / HR 等异构老旧系统的数据流转场景：业务人员一句自然语言，把多张结构各异的导出表
自动解析、关联、计算，产出**目标系统能直接导入**的标准文件，异常行自动隔离并附带日志。

## 快速开始

```bash
# 1. 安装依赖
pip install pandas openpyxl streamlit python-dateutil

# 2. 生成演示数据（ERP 加班导出 / OA 请假单 / HR 年假余额 + 空白导入模板）
python make_demo.py

# 3. 启动工作台
streamlit run app.py

# 4. 命令行跑三条验收自检
python verify.py
```

无 GPU、无 API Key 也能完整运行：表头映射与条件解析走规则引擎，数值计算永远由确定性代码完成。

## 目录结构

```
agent_app/
├─ app.py                 # Streamlit 交互工作台（4 个页面）
├─ verify.py              # 验收自检（逻辑精度 / 格式兼容 / 抗错鲁棒）
├─ make_demo.py           # 演示数据与目标模板生成
├─ core/
│  ├─ fields.py           # 字段语义词典：异构表头 -> 标准字段
│  ├─ parser.py           # 脏表解析：表头探测、类型归一、空行隔离
│  ├─ mapper.py           # 字段映射（词典 -> 大模型兜底 -> 人工覆盖）
│  ├─ filters.py          # 自然语言筛选条件 -> pandas 掩码
│  ├─ rules.py            # 业务规则技能库（确定性计算）
│  ├─ exporter.py         # 目标模板导出 + 异常日志
│  ├─ agent.py            # 智能体编排：意图 -> 计划 -> 执行 -> 交付
│  └─ llm.py              # 可选大模型适配（OpenAI 兼容）
└─ data/
   ├─ demo/               # 演示源表（含注入的脏数据）
   └─ templates/          # 目标系统空白导入模板
```

## 四层能力实现

| 层 | 任务书要求 | 本实现 |
|---|---|---|
| 意图与表头解析 | 语义理解与异构字段对齐 | 全半角/标点归一化 + 同义词词典 + 模糊匹配；易混淆字段（天/小时）做互斥惩罚；表角色自动判定 |
| 复杂逻辑与筛选计算 | 跨表关联判定与业务规则换算 | 规则引擎按员工逐单抵扣年假，超出部分转事假并**分行记录**；支持部门/时间段/时长等动态筛选 |
| 字段重组与格式转换 | 多源聚合与结构清洗 | 目标模板驱动列名/列序/类型，数值写数字、日期写日期，无合并单元格与公式 |
| 异常兜底 | 不因个别错误崩溃 | 行级隔离（空行、脏字符、缺关联键、日期/数值不可解析），异常日志随导出文件一并交付 |

## 内置技能

1. **假期余量结算** —— OA 请假单 × HR 年假余额表：优先扣减年假额度，超出部分自动转为事假并分离记录，逐单维护剩余余额。
2. **加班记录转 HR 导入** —— ERP 加班导出：部门/时间段/时长筛选，小时数换算（时长字段缺失时用起止时间差），加班类型按星期/法定节假日判定。
3. **通用字段映射导出** —— 未知结构报表：逐列人工指定映射或写计算表达式，直接产出导入模板（应对未来新增报表）。

新增业务只需在 `core/rules.py` 增加一个 `Skill` 子类，主流程无需改动。

## 准确性保障

- **数值与逻辑判定全部由确定性代码完成**，大模型只参与"理解"（意图识别、未知表头映射兜底），不参与算数——不存在数值捏造或漂移。
- `verify.py` 用固定用例把引擎结果与人工 Excel 公式复算结果**逐格比对**，保证计算精度。
- 大模型未配置时自动降级为纯规则模式，功能完整、可离线运行。

## 验收自检结果

| 验收项 | 标准 | 检查方式 |
|---|---|---|
| 逻辑计算精度 | 与人工电子表格公式结果完全一致 | 固定用例（含余额 0 / 余额不足 / 缺余额记录 / 非年假单据）逐格比对 |
| 格式兼容度 | 可无缝导入目标系统，不触发格式报错 | 与空白模板比对列名列序、检查合并单元格与单元格类型 |
| 抗错鲁棒性 | 注入干扰字符/空行不宕机 | 注入 `!!!` / `###` / `abc` 与空行，检查正常数据完整性与异常日志 |
